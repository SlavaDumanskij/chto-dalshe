# ЧтоДальше (MVP)

Учебный курсовой проект по разработке мобильного приложения для подбора досуговых активностей (ИТМО, 2026).

## Структура репозитория
* `/mobile` — клиентское приложение (React Native / Expo / TypeScript)
* `/backend` — серверная часть и API (FastAPI / SQLAlchemy / PostgreSQL)
* `/docs` — техническая документация, ТЗ и спецификации

## Правила командной разработки
1. Основная ветка — `main`.
2. Для каждой задачи создаётся отдельная ветка: `feature/название-фичи` или `fix/описание`.
3. Все изменения вливаются только через **Pull Request** с обязательным код-ревью.
